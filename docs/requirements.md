# 要件定義（合意済みのドラフト）

## 目的
移動中に、スマホの内蔵 GNSS が今つかんでいる衛星とその受信状態をリアルタイムに見る。

## 前提・方針
- **Android のネイティブアプリ**（Kotlin / Jetpack Compose）。配布は **APK のみ**
- iPhone は対象外（OS が衛星ごとの情報を出さない）。**Google Play での公開も対象外**
- Play ストアを通さないため、インストール時に「提供元不明のアプリ」の許可が必要

## データ
- 内蔵 GNSS から **1 秒ごと** に取得する（外付けの受信機は使わない）
  - 衛星ごと: 測位系、衛星番号（SVID）、受信強度（C/N0）、方位、仰角、位置計算に使っているか
  - 位置: 緯度、経度、精度、測位状態（未測位 / 2D / 3D）
- 位置データは端末内だけで処理し、外部には送らない

## 画面・機能
- **スカイプロット**: 北を上にした円に、各衛星の方角と高さを点で表示
- **衛星一覧**: 測位系（GPS / みちびき / GLONASS / Galileo / BeiDou など）、SVID、C/N0、方位、仰角、使用の有無
- **受信強度の棒グラフ**
- **現在地と測位状態**: 緯度・経度・精度・未測位 / 2D / 3D、使用 / 捕捉の衛星数
- **地図と移動の軌跡**: OpenStreetMap（オフラインで使える形）。軌跡は捕捉している衛星数で色分け
- **バックグラウンド記録**: 画面を消していても、通知を出したまま記録を続ける。CSV / GPX で書き出す
- 見た目は Sony nav-u / Panasonic ストラーダの測位情報画面のようなカーナビ風（暗い背景、緑 = 使用 / 青 = 捕捉 / 灰 = 弱い）
  - 画面ラフ: https://cursor.com/canvas/store-6b8df988-9d93-4e08-80bf-9b57d543e5ff/32fc77e4-3355-45ae-becf-fe84d10a0c34

## v0.3 の詳細（地図・記録）
- 地図: osmdroid + OpenStreetMap 標準タイル。北が上で固定、現在地への追従と夜（反転）/ 昼の切り替え
  - タイル利用ポリシーに従い、識別できる User-Agent を送り、同時ダウンロードは 2 本まで。範囲の一括ダウンロードはしない
  - 一度表示したタイルは端末内にキャッシュ（最大 300MB）し、その範囲はオフラインでも表示する
  - 帰属表示「© OpenStreetMap contributors」を常に表示
- 軌跡: 使用衛星数で色分け（8 以上=緑、5〜7=黄、4 以下=橙）。5 秒以上の空白は点線
- 記録: フォアグラウンドサービス（`foregroundServiceType="location"`、`FOREGROUND_SERVICE_LOCATION`）。記録中は通知を表示し、通知から停止できる。Android 13 以降は `POST_NOTIFICATIONS` を記録開始時に求める
  - 記録はアプリが前面にあるときにボタンで開始する（バックグラウンド位置情報の権限は求めない）
  - 1 秒ごとの測位のうち、測位済み・新しい時刻の点だけを記録: 時刻、緯度、経度、高度、精度、速度、使用 / 捕捉衛星数
  - 記録はアプリ専用領域に 1 点ずつ追記し、最後の 1 回分を保持（次の記録開始で上書き）
- 書き出し: Storage Access Framework（保存先をユーザーが選ぶ）で CSV と GPX 1.1

## v0.4 の詳細（nav-u 風の見た目）
- 参考: Sony nav-u の GPS 情報画面と地図画面。公式の画面画像は取得できなかったため、公開されている説明（大きなタッチボタンの下部ツールバー、自動ディマーの昼夜、自車マークの色 = 赤 / 橙 / 灰で受信レベルを示す、使用 = 緑 / 受信中 = 青、緯度・経度・日時・速度・高度の項目、未測位は `---`、光沢のある家電風の外観）を元にしている。ロゴ・商標・画面そのものは使わない
- タイトル帯、光沢ボタンの下部ツールバー、昼 / 夜 / 自動の表示モード（全画面と地図に適用、端末に保存）、パネルのグラデーション、へこんだ値ボックス、金属風ベゼルの文字盤、光沢つきマーカーと強度バー
- 下部ツールバーの「表示」ボタンで自動 → 昼 → 夜。システムバーのアイコンも昼夜に合わせる
- 文字色は昼夜どちらもコントラスト比 4.5 以上（本文 6.5 以上）をテストで確認
- 機能・データ形式の変更はなし。v0.2 の余白対応（safeDrawing）は維持

## GitHub / CI
- リポジトリ: `mashishiii/gnss-monitor`（公開）
- GitHub Actions
  - `ci.yml`: `main` への push と PR で、ユニットテストとデバッグ APK のビルド。APK は成果物として保存
  - `release.yml`: `v*` タグで署名付き APK をビルドし、GitHub Releases に添付
- 署名鍵とパスワードはリポジトリの Secrets に置き、コードには入れない
- 位置情報のログ（CSV / GPX）と署名ファイルはコミットしない

## 対象外
- iPhone 対応
- Google Play での公開
- 過去の記録の分析、衛星の軌道の予測
