# GNSS モニター (gnss-monitor)

移動中に、スマホの内蔵 GNSS（GPS・みちびき・GLONASS・Galileo・BeiDou など）が **今どの衛星をつかんでいるか** を見るための Android アプリです。カーナビ（Sony nav-u / Panasonic ストラーダ）の「測位情報」画面のような、暗い背景の見た目を目指しています。

- Android 専用のネイティブアプリ（Kotlin + Jetpack Compose）
- 配布は APK のみ（Google Play では公開しません）
- 要件は [docs/requirements.md](docs/requirements.md)、画面ラフは [こちら](https://cursor.com/canvas/store-6b8df988-9d93-4e08-80bf-9b57d543e5ff/32fc77e4-3355-45ae-becf-fe84d10a0c34)

## 見た目（nav-u 風）

Sony nav-u の測位情報（GPS 情報）画面や地図画面の雰囲気を参考にした、カーナビ風の見た目です。ロゴや意匠そのものは使わず、質感と配色だけを真似ています（公式の画面画像は入手できなかったため、公開されている説明と製品の特徴をもとにしています）。

- **タイトル帯**: 画面上部に青いグラデーションの帯。左に画面名、右に GPS の受信レベルのランプ（赤 = 測位中 / 橙 = 衛星は捕捉しているが測位前 / 灰 = 未受信。nav-u の自車マークの色の意味づけに倣う）
- **下部ツールバー**: 画面切り替えの大きな光沢ボタン（上半分にハイライトのある縦グラデーションと、上が明るく下が暗い縁）。選択中のボタンは青く光る。右端の「表示」ボタンで **自動 → 昼 → 夜** を切り替え（nav-u の昼夜切り替えに倣う。「自動」は端末のダークテーマに従う。選択は端末に保存）
- **昼夜テーマ**: 夜は暗い青黒、昼は明るい白青。測位状況・衛星一覧・地図・下部ツールバー・記録バーのすべてに適用。地図の色（夜は反転した暗い地図）も同じ切り替えに連動
- **パネルと値ボックス**: パネルは上が明るく下が暗いグラデーションと細い縁。緯度・経度・高度・日時の値は「へこんだ表示枠」（液晶風）で、測位できていないときは `---`
- **スカイプロット**: 中央が明るい放射グラデーションの文字盤と、金属風の二重のベゼル。マーカーは光沢つき
- **受信強度バー**: 上が明るいグラデーションと左のハイライトを付けた棒（衛星一覧のバーも同様）
- **衛星一覧**: 青い見出し帯と、1 行おきに薄く色を付けた行
- **地図**: 北が上の方位マーク（赤い針が北）、速度・高度の表示、赤い自車マーク
- 昼夜どちらも文字が読めることを、配色のコントラスト比のテストで確認しています

色の意味: 緑 = 位置計算に使用中 / 青 = 捕捉（受信できている）/ 灰 = 弱い。

## 記録と書き出し（v0.3）

1. 下の「地図」を開き、「● 記録開始」を押す（初回は通知の許可を求められます。許可すると記録中の通知が出ます）
2. 画面を消したり他のアプリに切り替えても、通知を出したまま 1 秒ごとに記録を続けます。通知の「記録停止」か、地図画面の「■ 記録停止」で止めます
3. 「CSV」「GPX」を押すと保存先を選ぶ画面が開くので、ファイル名と場所を決めて保存します（Google ドライブなども選べます）

- 記録する項目: 時刻（UTC）、緯度、経度、高度、精度、速度、使用衛星数、捕捉衛星数
- CSV の列: `time_utc,latitude,longitude,altitude_m,accuracy_m,speed_mps,satellites_used,satellites_visible`
- GPX 1.1: `ele` `time` `fix` `sat` に加え、速度・精度・捕捉衛星数を拡張要素（`gm:speed` `gm:accuracy` `gm:satsVisible`）に入れます
- アプリ内に残るのは **最後の 1 回分の記録だけ** です（アプリを閉じても残り、次に記録を始めると上書き）
- 記録は位置情報の権限が「アプリの使用中のみ許可」で動きます（記録はアプリが前面にあるときにボタンで始めるため）

## 地図について

- 地図は [OpenStreetMap](https://www.openstreetmap.org/copyright) のタイルを [osmdroid](https://github.com/osmdroid/osmdroid) で表示します（© OpenStreetMap contributors）
- [タイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/) に沿って、アプリを識別できる User-Agent（`GNSSMonitor/バージョン (+https://github.com/mashishiii/gnss-monitor)`）を送り、同時ダウンロードは 2 本までにしています
- **一度表示したタイルだけ** を端末内（最大 300MB）にキャッシュし、電波が無いときもその範囲は表示できます。まだ表示したことのない範囲はオフラインでは出ません（範囲の一括ダウンロードは規約上行いません）
- 地図の色（夜は反転した暗い地図 / 昼は通常）は、下の「表示」ボタン（自動 / 昼 / 夜）に連動します。「追従中 / 現在地」ボタンで現在地への追従に戻ります。地図を指で動かすと追従は解除されます

## インストール方法（APK）

1. このリポジトリの [Releases](https://github.com/mashishiii/gnss-monitor/releases) を Android のスマホで開く
2. 最新バージョンの `gnss-monitor-vX.Y.Z.apk` をダウンロードする
3. ダウンロードした APK を開く。「この提供元のアプリを許可」のような画面が出たら、ブラウザ（または使っているファイル管理アプリ）に **「提供元不明のアプリ」のインストールを許可** してインストールする
4. 初回起動時に位置情報の許可（ACCESS_FINE_LOCATION）を求められるので許可する。屋外で空が開けた場所のほうが衛星を多くつかめます

> Play ストアを通さない APK のため、インストール時に上記の許可が必要です。インストール後は許可を戻して構いません。

## 位置情報について

位置情報や衛星のデータは端末の中だけで処理し、外部のサーバーには送りません。将来の記録機能で書き出す CSV / GPX などの **位置情報のログは、リポジトリにコミットしません**（`.gitignore` で `*.csv` `*.gpx` `logs/` を除外しています）。署名用の鍵（`*.jks` `*.keystore`）も同様です。

## 開発

必要なもの: JDK 17、Android SDK（compileSdk 37.1）。

```sh
./gradlew testDebugUnitTest assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

- `main` への push と PR で CI（[.github/workflows/ci.yml](.github/workflows/ci.yml)）がテストとデバッグ APK のビルドを実行します
- `v0.1.0` のようなタグを push すると、[release.yml](.github/workflows/release.yml) が署名付き APK をビルドし、GitHub Releases に公開します
  - 署名には Secrets の `KEYSTORE_BASE64` `KEYSTORE_PASSWORD` `KEY_ALIAS` `KEY_PASSWORD` を使います（ローカルでは環境変数 `KEYSTORE_FILE` なども同じ名前。未設定なら未署名でビルドされます）
  - バージョン名はタグから、バージョンコードは Actions の実行番号から自動で決まります

## ディレクトリ構成

```
app/src/main/java/io/github/mashishiii/gnssmonitor/
├─ data/        GNSS の取得（LocationManager / GnssStatus）、測位系名・測位状態のロジック、記録（TrackRecorder）と CSV / GPX
├─ ui/          MainScreen（権限・画面切り替え・前回のクラッシュ表示）
├─ ui/status/   測位状況画面（スカイプロット・強度バー・情報ボックス）と座標計算
├─ ui/map/      地図画面（osmdroid、軌跡・現在地の描画、記録ボタン）
├─ logging/     記録用のフォアグラウンドサービス
├─ ui/list/     ViewModel と、ヘッダー + 衛星一覧の画面
└─ ui/theme/    nav-u 風の昼夜テーマ（配色）と、光沢ボタン・パネル・タイトル帯などの部品
```
